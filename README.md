# Cat vs Dog Image Classification

## Overview

This project is a Deep Learning-based image classification system that identifies whether an image belongs to a cat or a dog. The model is built using Convolutional Neural Networks (CNNs) with TensorFlow and Keras.

The project demonstrates the application of Computer Vision and Deep Learning techniques for automated image recognition.

---

## Features

- Image preprocessing and normalization
- Convolutional Neural Network (CNN) architecture
- Cat and Dog image classification
- Model training and evaluation
- Prediction on unseen images

---

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib

---

## Project Workflow

1. Load Cat and Dog image dataset
2. Preprocess and normalize images
3. Build CNN model
4. Train the model
5. Evaluate model performance
6. Predict image classes

---

## CNN Architecture

The model uses:

- Convolutional Layers (Conv2D)
- Max Pooling Layers
- Flatten Layer
- Dense Layers
- Output Layer for Binary Classification

---

## Results

The trained model successfully classifies images into:

- Cat
- Dog

The model was evaluated using classification accuracy and validation metrics.
